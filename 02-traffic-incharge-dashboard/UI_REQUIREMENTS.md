# Traffic In-charge Dashboard UI Requirements

## Main Screen Layout

| Area | Content |
| --- | --- |
| Top bar | City zone, active emergencies, system status |
| Map | Ambulances, signals, roads, incidents, predicted traffic zones |
| Alert feed | Ambulance approaching, road blocked, traffic predicted |
| Signal control panel | Selected signal, current state, manual controls |
| Ambulance list | Active vehicles, route, priority, ETA |

## Alerts

Examples:

- Ambulance AMB-07 approaching Signal S3
- Signal S3 switched to green
- Road R4 has high congestion
- AI predicts heavy traffic near Office District at 6 PM
- Ambulance AMB-11 needs route priority

## Signal Controls

Each signal should support:

- Green
- Yellow
- Red
- Emergency priority mode
- Normal mode

## UI Priority

This screen should look like a control room dashboard. Use strong visual status indicators and a live event feed.
