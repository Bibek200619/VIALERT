# Ambulance Driver Dashboard

The Ambulance Driver Dashboard is the driver-facing part of VIALERT. It helps the ambulance driver understand where to go, which route is active, and which signals are green ahead.

## Goal

Give the ambulance driver a simple live navigation view for emergency movement.

## Driver Should See

- Current ambulance location
- Base/start location
- Destination or hospital
- Recommended route
- Green lights ahead
- Red or inactive lights
- Blocked or congested roads
- Estimated arrival time
- Next instruction

## Important Note

For the MVP, live GPS data may not be available. Ambulance movement can be simulated using timed updates along the selected route.

## Main Actions

- Start ambulance trip
- View current route
- View upcoming green signal
- View rerouting alert
- End trip

## Success Criteria

- Driver can clearly see where the ambulance is.
- Driver can see where to go next.
- Driver can identify green lights on the route.
- Dashboard updates as the ambulance moves.
