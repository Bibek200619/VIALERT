# User Stories

## Emergency Dispatcher

- As a dispatcher, I want to create an emergency request so that the system can prepare a route.
- As a dispatcher, I want to see the ambulance ETA so that I can monitor emergency progress.
- As a dispatcher, I want to see if the route changes so that I understand why the ambulance is being redirected.

## Traffic Operator

- As a traffic operator, I want to see which signals are being prioritized so that I can supervise the corridor.
- As a traffic operator, I want the system to reject blocked roads so that unsafe routes are avoided.
- As a traffic operator, I want signals to return to normal after the ambulance passes so that normal traffic resumes.

## Ambulance Driver

- As a driver, I want a clear route to the hospital so that I can focus on driving.
- As a driver, I want the route to update when a road is blocked so that I avoid delays.

## Hackathon Judge

- As a judge, I want to see the emergency route, rerouting, and signal priority in one demo so that I can understand the value quickly.
