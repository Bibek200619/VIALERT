# Information Architecture

## Main Navigation

- Dashboard
- Emergency Request
- Incidents
- Signals
- Metrics
- Logs

## Dashboard Layout

| Area | Purpose |
| --- | --- |
| Top bar | Project name, emergency status, reset/demo controls |
| Map area | Road network, route, ambulance, signals, incidents |
| Left panel | Emergency request and route summary |
| Right panel | Signal priority and incident controls |
| Bottom panel | Timeline, metrics, event log |

## Primary User Flow

1. Open dashboard.
2. Click Start Emergency.
3. Select source and hospital.
4. View calculated route.
5. Add accident or congestion.
6. Watch rerouting.
7. Watch signal priority activate.
8. End simulation and view result.

## Judge-Friendly Flow

The demo should be understandable within 60 seconds. The first screen should already show a city map, ambulance, hospital, and Start Emergency button.
