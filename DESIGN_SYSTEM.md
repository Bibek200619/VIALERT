# Design System

## Visual Identity

VIALERT should feel like a modern traffic control dashboard: serious, clear, and fast to understand.

## Colors

| Purpose | Color |
| --- | --- |
| Background navy | `#091522` |
| Panel navy | `#122436` |
| Cyan route | `#46D8EE` |
| Green priority | `#49E3A4` |
| Red incident | `#FF6B73` |
| White text | `#F4F8FB` |
| Muted text | `#9DB0C2` |

## Typography

- Use Aptos, Inter, or system sans-serif.
- Use large numeric metrics for ETA and distance.
- Keep dashboard labels short.

## UI Components

- Map canvas
- Status header
- Emergency request card
- Route summary panel
- Signal status list
- Incident controls
- Metrics cards
- Event log

## Map Styling

- Roads: thin muted lines
- Active route: bright cyan
- Emergency corridor: green glow or marker
- Incident: red marker
- Hospital: green cross or clear hospital label
- Ambulance: high-contrast moving marker
