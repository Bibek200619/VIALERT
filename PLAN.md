# 24-Hour MVP Plan

## Build Priority

1. Build the visual city map.
2. Add road graph data.
3. Add ambulance start and hospital destination.
4. Implement route calculation.
5. Add traffic and incident simulation.
6. Add rerouting when roads change.
7. Add traffic-light priority simulation.
8. Add dashboard metrics.
9. Polish the demo story.
10. Prepare pitch and backup screenshots.

## Suggested Timeline

| Time | Work |
| --- | --- |
| Hour 0-2 | Finalize scope, UI layout, road graph format |
| Hour 2-5 | Build frontend map/dashboard |
| Hour 5-8 | Implement graph and route calculation |
| Hour 8-11 | Add ambulance movement and ETA |
| Hour 11-14 | Add incidents, congestion, and rerouting |
| Hour 14-17 | Add signal-priority simulation |
| Hour 17-20 | Add metrics, logs, and UI polish |
| Hour 20-22 | Test demo scenarios |
| Hour 22-24 | Pitch rehearsal, screenshots, README cleanup |

## Demo Scenario

1. Start ambulance from Point A.
2. Select City Hospital as destination.
3. Show normal route.
4. Add accident on main road.
5. Trigger rerouting.
6. Show traffic lights turning green on the new route.
7. Show ambulance reaching hospital.
8. Display total delay avoided and number of signals coordinated.

## Team Split

- UI developer: dashboard, map, panels, styling
- Algorithm developer: graph, routing, ETA, rerouting
- Simulation developer: traffic, ambulance movement, signals
- Pitch/documentation person: README, slides, demo script, screenshots
