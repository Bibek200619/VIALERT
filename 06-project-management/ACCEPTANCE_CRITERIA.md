# Acceptance Criteria

## Ambulance Dashboard

- Ambulance driver can see base location.
- Ambulance driver can see destination/hospital.
- Ambulance driver can see active route.
- Ambulance driver can see green lights on route.
- Ambulance marker moves during simulation.

## Traffic In-charge Dashboard

- Operator can see active ambulances.
- Operator receives alerts when ambulance approaches signal.
- Operator can change signal state.
- Operator can see traffic prediction warnings.
- Operator can view event log.

## AI Prediction

- Model/API predicts congestion level for an area or road.
- Prediction considers time and at least two other factors.
- Prediction appears on dashboard.
- Prediction can influence route cost or warning display.

## Overall MVP

- App runs locally.
- Demo can be shown in under 5 minutes.
- Data files are readable and editable.
- No real government data is required.
- System clearly shows what is simulated.
