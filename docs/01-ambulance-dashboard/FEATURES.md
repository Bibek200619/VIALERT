# Ambulance Dashboard Features

## Must-Have Features

- Show ambulance on real map
- Show base/start point
- Show hospital/destination
- Show route generated by A*
- Show green-light corridor
- Simulate ambulance movement
- Show ETA
- Show reroute alert

## Good-To-Have Features

- Voice-style instruction text
- Distance to next signal
- Warning when traffic is predicted ahead
- Trip completion summary

## Future Features

- Real GPS tracking
- Driver mobile app
- Audio alerts
- Integration with hospital system
- Driver authentication
