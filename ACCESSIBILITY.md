# Accessibility

## Dashboard Accessibility Goals

- Use high contrast for text and map elements.
- Do not rely only on color for route and incident status.
- Add labels or icons for ambulance, hospital, incidents, and signals.
- Keep buttons large enough for fast demo interaction.
- Ensure text is readable on a projector.

## Color Meaning

| Meaning | Visual |
| --- | --- |
| Active route | Cyan line with label |
| Signal priority | Green light and text |
| Incident | Red marker with warning label |
| Ambulance | Distinct icon and label |
| Hospital | Green hospital marker |

## Keyboard Support

For the MVP, support keyboard access for:

- Start Emergency
- Add Incident
- Reset Demo
- Toggle Congestion

## Reduced Motion

If possible, add a slower demo mode or pause button so judges can inspect the route and signal changes.
