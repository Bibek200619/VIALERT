# Acceptance Criteria

The MVP is ready for the next round when the following are true.

## Core Demo

- User can start an emergency request.
- Ambulance appears on the map.
- Hospital appears on the map.
- Route appears between ambulance and hospital.
- Ambulance moves along the route.
- Traffic signals on the route change to priority green.
- Incident can be added during the demo.
- System reroutes when the incident blocks the current path.
- Dashboard shows ETA, active route, and event log.

## Presentation Readiness

- Demo can be completed in under 3 minutes.
- UI is readable on a projector.
- Demo has a reset button.
- Team can explain what is simulated and what is future work.
- There are screenshots available in case the live demo fails.

## Technical Readiness

- Project runs from a clean checkout.
- Required commands are documented.
- Road data is stored in a readable JSON format.
- Routing logic is separated from UI code.
- No sensitive keys are required for local demo.
